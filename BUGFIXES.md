# Исправления багов онлайн-режима

## Исправленные проблемы

### 1. ✅ Десинхронизация игроков
**Проблема:** Игроки видели разное состояние боя, у одного матч заканчивался раньше, у другого еще оставалось HP.

**Решение:**
- Добавлена регулярная синхронизация состояния каждые 3 фрейма от хоста к гостю
- Хост теперь отправляет полное состояние обоих бойцов (позиции, HP, состояния)
- Гость применяет полученное состояние для синхронизации
- Добавлен флаг `gameOver` в синхронизируемое состояние

**Файлы:** `src/game.ts` (функция `update`)

### 2. ✅ Разные результаты матча
**Проблема:** У разных игроков определялись разные победители.

**Решение:**
- Хост стал авторитетным источником для определения победителя
- Хост отправляет финальное состояние с флагом `gameOver: true`
- Хост отправляет событие `battle_over` с результатом на сервер
- Сервер транслирует результат гостю
- Оба клиента используют одинаковую логику определения победителя

**Файлы:** `src/game.ts` (функция `update`), `index.js` (обработчик `battle_over`)

### 3. ✅ Отсутствие кнопки возврата в меню
**Проблема:** После окончания боя не появлялась кнопка для возврата в главное меню, оставался только темный экран.

**Решение:**
- Создана отдельная функция `showBackButton()` для показа кнопки
- Кнопка показывается с задержкой 500мс после окончания боя
- Улучшена интеграция с Telegram MainButton (цвет, текст)
- Добавлены более надежные CSS стили для HTML кнопки (position: fixed, z-index: 10000)
- Кнопка теперь использует `window.location.href` вместо `replace` для лучшей совместимости
- Добавлен обработчик `onclick` напрямую в JavaScript

**Файлы:** `src/game.ts` (функции `handleBattleOutcome`, `showBackButton`, `draw`)

### 4. ✅ Улучшена стабильность соединения
**Решение:**
- Сокет отключается через 1 секунду после окончания боя
- Сервер очищает матч с задержкой 2 секунды для гарантии доставки финального состояния
- Улучшена обработка состояния на сервере

**Файлы:** `src/game.ts`, `index.js`

## Как проверить исправления

1. Запустите сервер:
   ```bash
   cd server
   npm start
   ```

2. Откройте игру в двух разных браузерах/вкладках

3. Начните онлайн-матч

4. Проверьте:
   - ✅ Оба игрока видят одинаковое состояние боя
   - ✅ HP синхронизируется между игроками
   - ✅ Матч заканчивается одновременно для обоих
   - ✅ Оба видят одного и того же победителя
   - ✅ После боя появляется кнопка "ВЕРНУТЬСЯ В МЕНЮ"
   - ✅ Кнопка работает и возвращает в главное меню

## Технические детали

### Архитектура синхронизации
- **Хост (host)** - авторитетный клиент, который:
  - Запускает симуляцию боя
  - Отправляет состояние гостю каждые 3 фрейма
  - Определяет победителя
  - Отправляет финальный результат на сервер

- **Гость (guest)** - клиент, который:
  - Получает состояние от хоста
  - Применяет полученное состояние для синхронизации
  - Отображает бой на основе данных хоста

- **Сервер** - транслирует сообщения между клиентами:
  - `battle_state` - состояние боя от хоста к гостю
  - `battle_over` - финальный результат от хоста к гостю

### Формат синхронизируемого состояния
```typescript
interface SyncedBattleState {
  tick: number;           // Номер фрейма
  gameOver: boolean;      // Флаг окончания боя
  host: SyncedFighterState;   // Состояние бойца хоста
  guest: SyncedFighterState;  // Состояние бойца гостя
}

interface SyncedFighterState {
  x: number;
  y: number;
  hp: number;
  fighterState: string;
  hitTimer: number;
  charType: string;
  color: string;
}
```

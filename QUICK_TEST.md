## Как протестировать:

### 1. Перезапустите сервер (если запущен):
```bash
# Остановите сервер (Ctrl+C)
# Затем запустите снова:
node index.js
```

### 2. Очистите кэш браузера:
- **Chrome/Edge**: Ctrl+Shift+Delete → Очистить кэш
- **Firefox**: Ctrl+Shift+Delete → Кэш
- Или откройте в режиме инкогнито

### 3. Откройте игру в двух окнах:
- Окно 1: `http://localhost:3000`
- Окно 2: `http://localhost:3000` (в другом браузере или инкогнито)

### 4. Начните матч:
- В обоих окнах нажмите "ИГРАТЬ"
- Игроки должны автоматически соединиться

### 5. Проверьте после окончания боя:
- ✅ Экран становится темным
- ✅ Показывается имя победителя
- ✅ Показывается текст "ПОБЕДИТЕЛЬ"
- ✅ Показывается подсказка "Нажмите кнопку ниже..."
- ✅ **ПОЯВЛЯЕТСЯ ФИОЛЕТОВАЯ КНОПКА "ВЕРНУТЬСЯ В МЕНЮ"**
- ✅ При клике на кнопку происходит переход в меню

## Отладка:

### Если кнопка не появляется:

1. **Откройте консоль браузера** (F12 → Console)

2. **Проверьте логи:**
   - Должно быть: `"Battle outcome handled, showing back button..."`
   - Должно быть: `"Attempting to show back button..."`
   - Должно быть: `"Back button element: <button>"`
   - Должно быть: `"Back button styled and visible"`

3. **Если видите ошибку:**
   - `"Back button element not found!"` → Проверьте game.html, должен быть элемент с id="backBtn"
   - Другие ошибки → скопируйте и отправьте мне

4. **Проверьте элемент кнопки:**
   - F12 → Elements → Найдите `<button id="backBtn">`
   - Проверьте стили: `display: block`, `visibility: visible`, `opacity: 1`

### Если кнопка есть, но не кликается:

1. Проверьте z-index (должен быть 10000)
2. Проверьте pointer-events (должен быть auto)
3. Попробуйте кликнуть несколько раз

# Инструкция по тестированию исправлений

## Быстрый старт

### 1. Запуск сервера
```bash
# Если сервер еще не запущен
cd server
npm install  # только при первом запуске
npm start
```

Сервер должен запуститься на порту 3000 (или указанном в .env)

### 2. Тестирование онлайн-режима

#### Вариант А: Два браузера на одном компьютере
1. Откройте `http://localhost:3000` в Chrome
2. Откройте `http://localhost:3000` в Firefox (или в режиме инкогнито Chrome)
3. В обоих окнах:
   - Выберите персонажа (если нужно)
   - Нажмите "ИГРАТЬ"
4. Игроки должны автоматически соединиться

#### Вариант Б: Два устройства в одной сети
1. Узнайте IP вашего компьютера:
   ```bash
   ipconfig  # Windows
   # Найдите IPv4 адрес (например, 192.168.1.100)
   ```
2. На первом устройстве: `http://192.168.1.100:3000`
3. На втором устройстве: `http://192.168.1.100:3000`

#### Вариант В: Через Telegram WebApp
1. Настройте WEBHOOK_URL в server/.env
2. Отправьте /start боту
3. Откройте игру на двух разных устройствах через бота

## Известные ограничения

1. **Задержка сети**: При плохом соединении может быть небольшая задержка синхронизации (до 100мс)
2. **Первый запуск**: При первом подключении может потребоваться несколько секунд для установки соединения
3. **Мобильные браузеры**: На некоторых мобильных браузерах может потребоваться разрешение на WebSocket

## Отладка проблем

### Проблема: Игроки не соединяются
**Решение:**
1. Проверьте, что сервер запущен
2. Откройте консоль браузера (F12) и проверьте ошибки
3. Убедитесь, что Socket.IO подключен (должно быть сообщение "ПОИСК СОПЕРНИКА...")

### Проблема: Десинхронизация все еще происходит
**Решение:**
1. Очистите кэш браузера (Ctrl+Shift+Delete)
2. Перезапустите сервер
3. Убедитесь, что используется последняя версия dist/game.js

### Проблема: Кнопка не появляется
**Решение:**
1. Проверьте консоль на ошибки JavaScript
2. Убедитесь, что элемент #backBtn существует в game.html
3. Попробуйте обновить страницу после окончания боя

### Проблема: Разные победители
**Решение:**
1. Это должно быть исправлено. Если проблема сохраняется:
2. Проверьте версию файлов (должна быть последняя)
3. Очистите кэш и перезагрузите страницу
4. Проверьте логи сервера на ошибки

## Логи для отладки

### В консоли браузера (F12 → Console):
```
"Battle finished locally. Outcome: host"  // или "guest" или "draw"
```

### В консоли сервера:
```
Server reports battle over: host
```

## Контакты для сообщения о багах

Если вы нашли новый баг:
1. Откройте консоль браузера (F12)
2. Сделайте скриншот ошибок
3. Опишите шаги для воспроизведения
4. Укажите браузер и устройство
